# Code of Conduct

We are committed to providing a professional, respectful, and harassment-free environment for all participants.

## Expected Behavior

- Be respectful and constructive in technical discussions, code reviews, and issue threads.
- Focus on what is best for the codebase and community.
- Disagree constructively, with technical arguments and data.

## Unacceptable Behavior

- Harassment, trolling, derogatory comments, or personal attacks.
- Publishing private information without permission.
